- psutil — BSD-3-Clause

- Pillow — HPND
- python-docx — MIT
- pypdf — BSD-3-Clause
- ReportLab — BSD
- openpyxl — MIT
- python-pptx — MIT
- Beautiful Soup — MIT
- Python-Markdown — BSD-3-Clause
- imageio-ffmpeg and its FFmpeg binary — BSD-2-Clause for the wrapper; FFmpeg license terms apply to the bundled binary
- pillow-heif / libheif — BSD-3-Clause; bundled codec library terms apply
- pillow-avif-plugin / libavif — BSD-3-Clause; bundled codec library terms apply
- odfpy — Apache-2.0 / GPL terms as distributed upstream
- PyYAML — MIT
- defusedxml — PSF
- tomli and tomli-w — MIT
- striprtf — BSD-3-Clause

Package versions and full license texts are available from each upstream project and installed distribution. FFmpeg build information can be displayed by running the bundled converter engine with `-version` in a development environment.
