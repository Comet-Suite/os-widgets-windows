# Code of Conduct — OS Widgets v1.4.0 FINAL

Contact: m39776401@gmail.com

## Our pledge

We pledge to make OS Widgets a welcoming, lightweight, and useful project for everyone.

## Standards

- Be respectful and constructive
- No harassment, spam, or advertising
- Keep discussions focused on widgets, converter, performance, and Windows integration
- No telemetry, no tracking — respect user privacy

## Enforcement

Report issues to **m39776401@gmail.com** or via GitHub Issues. We will review and take appropriate action.
