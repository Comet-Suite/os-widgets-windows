## Troubleshooting

1. Run from source with console: `py os_widgets.py`
2. Settings → Diagnostics → Run diagnostics → Copy report
3. Include Windows version, OS Widgets version, and steps to reproduce

## File Converter & Code Converter

Enable in Settings → File Converter. Right-click any supported file → OS Widgets → choose output. Supports 100+ extensions, 60+ formats including Python, JS/TS, Jupyter, JSON.
