## Windows setup

1. Open the wallpaper file on GitHub.
2. Select **Download raw file**.
3. In Windows File Explorer, right-click the downloaded image.
4. Choose **Set as desktop background**.

For the cleanest widget layout, use **Fill** as the Windows background fit mode.
