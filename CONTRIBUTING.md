# Contributing

Thank you for your interest in OS Widgets.

1. Create a focused branch from `main`.
2. Keep the distributable application in the single `os_widgets.py` file.
3. Preserve disabled-by-default behavior for optional widgets.
4. Run `python -m py_compile os_widgets.py` before opening a pull request.
5. Test Windows-specific changes on Windows 10 or 11 when possible.
6. Include screenshots for user-interface changes.

Please keep pull requests focused and explain any resource-usage impact.
